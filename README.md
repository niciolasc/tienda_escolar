# Tienda Escolar

Aplicativo de consola desarrollado para el caso de estudio de **Programación
Aplicada** (Ingeniería Electrónica, Universidad Distrital Francisco José de
Caldas), cuyo objetivo es practicar el trabajo colaborativo con control de
versiones.

## Funcionalidades

- Registrar el nombre y precio de un producto.
- Mostrar la información de los productos registrados.
- Calcular el total de una compra sencilla.

## Estructura del proyecto

```
tienda_escolar/
├── main.py         # Punto de entrada, menú principal
├── productos.py     # Registro y visualización de productos
├── compra.py        # Cálculo del total de compra
└── README.md
```

## Cómo ejecutar

```bash
python3 main.py
```
